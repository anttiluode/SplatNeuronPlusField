# Grounding, recursive projection, and the field

Date: 2026-08-18

This note records a connection suggested by the model-collapse literature. It is a hypothesis bridge, not a result of Gate 1.

## First correction: do not call reality a high-frequency channel

The external world contains structure at many temporal and spatial scales.

Likewise, the ephaptic electric field in this repo is **endogenous**: it is generated by neural source currents. It is not a privileged channel from external reality into the brain.

The cleaner distinction is:

```text
external innovation
    information arriving from a source not generated by the current internal model

versus

recursive projection
    the system repeatedly observing / training on / reacting to consequences
    generated by its own current state or model
```

That distinction survives without a Fourier metaphor.

## What model collapse contributes

Shumailov et al. (Nature 2024, DOI `10.1038/s41586-024-07566-y`) show that recursive generative training can progressively lose tails of the original data distribution and eventually badly distort the learned distribution. Retaining some original data substantially reduces degradation in their language-model experiment.

Vu, Reeves and Wenger (`arXiv:2505.21677v2`) study multiple models training on one another's generated outputs. Their result is more nuanced: synthetic interaction can expose one model to concepts absent from its own data, while repeated interaction can also homogenize models on shared tasks.

Suresh, Thangaraj and Khandavally (AISTATS 2025) also show that collapse rate is regime-dependent: in simple discrete/Gaussian settings with many samples, forgetting can take many recursive generations. So `model collapse happens instantly` is not a general law.

Therefore the useful lesson is **not**:

```text
synthetic bad
real good
```

It is closer to:

> Repeated projection through the same limited family can discard distinctions. Information entering from an independently informative source can restore or introduce distinctions that the current model does not contain.

## Kynnys connection

This is the temporal/data-generational cousin of the Kynnys observation limit:

```text
if observation C collapses A and B,
more observations through the same C do not reconstruct the lost distinction.
```

Recursive model training repeatedly applies a learned observation/generation map to the data distribution. Rare distinctions that are not faithfully represented can disappear from later generations.

The remedy is often not `WAIT`.

It is `ROUTE`:

```text
new real measurement
another independently informative model
another sensor
another experiment
```

## Brain connection: prediction needs innovation

A minimal state-estimation picture is

```text
world state x_t
    -> sensory measurement y_t
    -> internal state h_t
    -> prediction yhat_t
```

with an innovation/residual

```text
innovation_t = y_t - yhat_t
```

Rao and Ballard's 1999 predictive-coding model explicitly uses feedback predictions and feedforward residual errors between prediction and lower-level activity.

The important conceptual point for this repo is that recurrent internal dynamics can transform, denoise, complete and replay existing information, but an internally generated signal is not automatically new evidence about the hidden external cause.

This is compatible with constructive replay. Nguyen et al. (`Nature 625, 110–118`, DOI `10.1038/s41586-023-06810-1`) found stimulus-specific cortical reactivations after visual experience; the content of those reactivations predicted future changes and increased separation in later sensory responses. Internal activity can reorganize the model. It simply should not be confused with an independent measurement of the world.

Sensory experience also steers representational drift in visual cortex (Bauer et al., Nature Communications 2024, DOI `10.1038/s41467-024-53326-x`). In the head-direction system, Ajabi et al. (Nature 2023, DOI `10.1038/s41586-023-05813-2`) found increased drift in darkness and strong recalibration by visual landmarks, with persistent experience-dependent biases.

So the brain analogy is not `model collapse = thought`.

A more defensible statement is:

> **Internal trajectories are continually re-anchored, contradicted and enriched by external innovations. Remove or narrow those innovations and internal representations can drift toward the statistics supported by the remaining loop.**

## Why Gate 1 suddenly matters

The Gate-1 slow milieu is diffusive. In the eigenbasis of the metric Laplacian,

```text
c_k(t) = exp[-(clearance + diffusion * lambda_k)t] c_k(0)
```

This is an exact property of the toy linear field.

Large-`lambda` spatial modes decay faster. In ordinary language: rapidly varying metric distinctions are smoothed more strongly than broad modes.

That means the filtering intuition has a precise version here:

> **The slow shared field is a selective forgetting operator in its own spatial vocabulary.**

Gate 1 showed the beneficial side. The task-relevant context lived in broad, physically aligned neighborhoods, so diffusion made useful history available to later nearby receivers.

The opposite task should exist too. If a needed distinction lives in rapidly alternating spatial modes, the same diffusion should destroy it.

Neither outcome is universally good or bad. The field defines a prior over which histories are cheap to retain and share.

## A useful linear-systems form

A large fraction of the connection can be written without biology:

```text
x_{t+1} = A x_t + B u_t
```

where `A` is the system's internally recurrent/relaxing operator and `u_t` is incoming innovation.

With `u_t = 0`, modes with gain below one contract. Repeated recursion cannot spontaneously recover a component that has become exactly absent from the state.

With informative `u_t`, those modes can be continually replenished.

This is not itself a discovery; it is classic state-space/control structure. What may be useful is treating observer loss, model-collapse loss, memory-field loss and sensory grounding with the **same accounting question**:

> Which modes/distinctions are internally self-sustaining, which decay, and which require recurrent external innovation?

## Candidate Gate 2 — innovation versus self-recurrence

Do not make another neural architecture yet.

Use the same linear field and construct a latent world with task information distributed across known metric eigenmodes.

Compare:

```text
A  closed decay / no new input
B  repeated self-generated reinjection from the current reduced state
C  fresh external samples from the original world process
D  mixture: self-generated replay + fraction p fresh external samples
E  independently generated samples that contain modes missing from the current model
F  fresh samples passed through the same lossy observer as the internal model
```

Measure over iterations:

```text
variance retained per field eigenmode
held-out task recovery
rare-mode / tail recovery
mutual-information proxy or cross-validated decoding of original latent factors
representation diversity
```

### Critical prediction

The strong hypothesis is **not** that only biologically real data rescue the system.

It is:

> **A loop can only recover a lost distinction when new input carries information about that distinction that is not already a deterministic consequence of the loop's current state.**

Therefore independently informative synthetic data should be able to rescue a missing distinction too.

If that happens, the scientific object is not `reality versus imagination`.

It is **innovation provenance**.

## Connection to the many-repo arc

This joins several previously separate failures/results without claiming they are the same mechanism:

```text
Kynnys Gate 4/5
    repeated evidence through one observation map cannot recover a collapsed distinction

TWC
    an output cannot identify a cause lying inside the nuisance/equivalence span

SplatNeuron Gate 13
    a learned observer vocabulary can make selected distinctions cheap to expose

SplatNeuronPlusField Gate 1
    a shared metric state makes selected histories cheap to expose to nearby receivers

model collapse
    repeated learned projection/resampling can erase underrepresented distinctions
```

A common question emerges:

> **Which distinctions survive repeated passage through the system's chosen observer, memory and communication vocabularies — and where does genuinely new information enter when they do not?**

That is a better bridge to the brain than `FFT brain`, `field brain`, or `Oja-in-parameter-space`.
